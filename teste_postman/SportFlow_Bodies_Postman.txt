SPORTFLOW — BODIES PARA TESTAR NO POSTMAN
========================================

Base URL: http://localhost:8080
Body: raw -> JSON
Para rotas protegidas: Authorization -> Bearer Token

ATENÇÃO: As rotas (exceto /auth/register e /auth/login) e os formatos dos relacionamentos são exemplos e dependem dos Controllers/DTOs implementados. Substitua todos os UUIDs ilustrativos pelos IDs retornados após cada cadastro. Não reutilize a senha de exemplo em produção.

1. USUÁRIO
POST http://localhost:8080/auth/register
{
  "name": "Henrique Teste",
  "email": "henrique.teste@sportflow.com",
  "password": "123456"
}

LOGIN — OBTER JWT
POST http://localhost:8080/auth/login
{
  "email": "henrique.teste@sportflow.com",
  "password": "123456"
}

OBSERVAÇÕES
- Execute os POSTs na ordem indicada por causa das chaves estrangeiras.
- O status de pagamento é definido como PENDENTE pelo PagamentoService.
- A tabela flyway_schema_history é gerenciada pelo Flyway e não requer POST.
- Se o Controller usar DTOs com campos como usuarioId ou quadraId, adapte o JSON ao DTO.
